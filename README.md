# Pesquisa de Mercado — Service-as-a-Software para Solopreneurs (WhatsApp-first)

Pesquisa de mercado crítica e orientada à decisão sobre a criação de um "agente administrativo digital" para solopreneurs brasileiros, com WhatsApp como interface principal, conforme briefing. Realizada em 01/08/2026 com pesquisa web em fontes primárias e oficiais.

## Conclusão em uma linha

**Decisão: VERTICALIZAR** — a tese horizontal ("funcionário digital faz-tudo para todo solopreneur") é reprovada pela evidência (disposição a pagar, churn de IA, Meta Business Agent); a versão estreita — **ciclo sessão→dinheiro (confirmação + cobrança Pix + conciliação) para psicólogos autônomos** — é executável e deve ser testada com um concierge pré-vendido (10 clientes, R$ 79–99/mês, 6 semanas, < R$ 5 mil) antes de qualquer construção de software. Score ponderado: **6,2/10**.
